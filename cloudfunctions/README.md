# 云函数目录

本目录用于 2.0 在线房间模式的微信云开发云函数。当前只建立目录和 TypeScript 配置骨架，具体业务实现由后续任务逐步补齐。

## 函数规划

| 目录                | 用途                           |
| ------------------- | ------------------------------ |
| `_shared`           | 云函数共享类型、常量和工具     |
| `login`             | 微信登录，创建或更新用户记录   |
| `createRoom`        | 创建在线房间并初始化房间状态   |
| `joinRoom`          | 加入房间并绑定座位             |
| `updateRoomState`   | 房主更新房间共享算点状态       |
| `confirmSettlement` | 房主确认结算并写入房间结算记录 |

## 编译约定

- 根项目 `tsconfig.json` 不包含 `cloudfunctions/**`，避免影响现有小程序前端编译。
- 云函数使用独立 `cloudfunctions/tsconfig.json`。
- 每个云函数后续可拥有自己的 `package.json` 和构建产物。
- 第一版云函数业务代码应通过 `_shared` 复用集合名、错误码和权限校验工具。
