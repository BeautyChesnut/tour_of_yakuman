## Why

正式重测期间需要快速区分用户输入、网络、服务版本和服务端异常，但当前用户提示与云托管日志缺少稳定关联。维护能力应自动运行，不能要求用户填写表单或复制技术信息。

## What Changes

- 云托管成功和失败响应附带 API 版本、服务版本、错误码与请求编号。
- 小程序自动识别服务版本不兼容，安全请求遇到瞬时网络失败时自动重试一次。
- 小程序自动上报关键在线动作失败和未处理异常，服务端仅写结构化运行日志。
- 本地算点草稿自动保存在本机并在重新进入本地模式时恢复。
- 房间版本冲突自动刷新最新房间状态，自动处理失败后才提示用户。

## Capabilities

### New Capabilities

- `retest-diagnostics`: 定义重测期间的自动诊断、版本兼容、安全恢复和隐私边界。

### Modified Capabilities

- 无。

## Impact

- 微信云托管响应格式、在线后端调用封装和运行日志。
- 小程序全局异常捕获、在线请求恢复和本地草稿存储。
- 隐私与发布文档、诊断和恢复测试。
