## ADDED Requirements

### Requirement: 系统自动关联诊断信息
云托管 SHALL 为响应提供 API 版本、服务版本和请求编号，并为失败提供稳定错误码；小程序 MUST 自动上报关键失败而无需用户操作。

#### Scenario: 在线请求失败
- **WHEN** 在线房间请求返回业务错误
- **THEN** 小程序使用友好文案提示用户
- **AND** 自动上报功能动作、错误码、请求编号、客户端版本和耗时

#### Scenario: 小程序发生未处理异常
- **WHEN** 小程序触发全局错误或未处理 Promise 拒绝
- **THEN** 系统尝试上报脱敏后的异常类别和客户端版本
- **AND** 上报失败不得影响用户继续使用

### Requirement: 系统自动检查服务兼容性
小程序 MUST 检查云托管响应中的 API 版本，并在不兼容时显示服务升级提示而不是房间失效提示。

#### Scenario: 服务版本过旧
- **WHEN** 云托管响应缺少所需 API 版本或版本低于客户端要求
- **THEN** 小程序提示在线服务正在升级
- **AND** 不把该错误归类为房间不存在

### Requirement: 系统仅安全自动恢复
系统 SHALL 对安全请求的瞬时网络失败自动重试一次，并在在线房间状态版本冲突时刷新最新状态。

#### Scenario: 安全请求短暂失败
- **WHEN** 登录或加入房间发生一次网络级失败
- **THEN** 小程序自动重试一次且不要求用户操作

#### Scenario: 写入请求失败
- **WHEN** 创建房间、房主转让、状态写入或确认结算失败
- **THEN** 小程序不得自动重复提交该写入

### Requirement: 本地草稿自动保存恢复
系统 SHALL 在本机保存未完成的本地算点草稿，并在再次进入相同本地玩法时自动恢复。

#### Scenario: 小程序意外退出后返回
- **WHEN** 用户录入本地算点数据后退出并重新进入相同玩法
- **THEN** 系统自动恢复最近有效草稿
- **AND** 不上传草稿内容

### Requirement: 诊断数据最小化
系统 MUST 仅上报白名单诊断字段，不得上报完整用户身份、昵称、头像、房间码、手牌或点数状态。

#### Scenario: 记录客户端失败事件
- **WHEN** 小程序上报失败诊断
- **THEN** 事件只包含版本、动作、错误码、请求编号、耗时、网络类型和时间
