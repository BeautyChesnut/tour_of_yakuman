## UI 手动验收清单

- 本局事件选择“荣和”时，可以选择 1-3 名和牌者；已选和牌者不能再选为放铳者，已选放铳者不能再选为和牌者。
- 双响或三响进入确认后，确认按钮显示“继续结算下一名”，当前和牌者、已完成数量和剩余和牌者清晰可见。
- 第一名和牌者确认后不更新四家点数、不新增正式结算记录、不推进局况；手牌、鸣牌和场面番型输入区被清空，宝牌、里宝牌、局况、放铳者和和牌者列表保持不变。
- 多人荣和进行中点击“回退上一名”，恢复最近完成和牌者的手牌、和牌张、鸣牌、场面番型、宝牌和里宝牌输入，并从已完成列表移除。
- 多人荣和进行中点击“取消多人荣和”，清理临时进度，四家点数、局况和正式结算记录不变。
- 所有和牌者确认完成后，只生成一条多人荣和结算记录；结果页按和牌者展示番符、役种和支付，并展示聚合后的四家点数变化和点差。
- 结果页点击“返回修改”时，恢复多人荣和的共享输入、和牌者列表、当前和牌者和已完成结果；重新确认后覆盖最近一条结算记录。
- 单人荣和、自摸、荒牌流局仍按原流程校验和结算。
