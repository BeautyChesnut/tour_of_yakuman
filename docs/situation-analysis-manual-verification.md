# 局势分析人工验收清单

本文档用于验证四麻与三麻局势分析、在线数据新鲜度和实战局况推演能力。当前能力是确定性的本地点数计算，不包含大模型、手牌向听、巡目或牌河攻防判断。

## 前置检查

- 使用最新代码重新编译微信小程序。
- 准备至少一组存在明显点差的四家点数，例如东 30000、南 18000、西 27000、北 25000。
- 后续在线验收可使用一个真实账号或开发者工具虚拟账号，不要求四位用户全部加入。

## 本地四麻

1. 首页选择“单机算点”，再选择“四人麻将”。
2. 确认算点工作台展示“局势分析 / 点数推演”入口。
3. 修改庄家和四家点数，确认摘要默认以当前庄家为分析视角。
4. 点击局势分析，确认详情页展示升一、升二、升三和跌四风险页签。
5. 依次切换东、南、西、北，确认当前点数、顺位、荣和条件、自摸条件和风险线即时变化。
6. 打开任一情景，确认结算后四家点数、顺位和符番门槛完整显示。
7. 确认页面提示符番组合只是合法点数门槛，不代表当前手牌拥有对应役。

## 牌局阶段与同点顺位

1. 依次选择东一局、南三局、南四局和西一局进入分析。
2. 确认分别显示前半场、后半场、默认半庄终局和延长局。
3. 切换到庄家视角，确认页面提示和牌或听牌流局可以连庄。
4. 将两家或四家点数设为相同，确认页面明确显示同点按东、南、西、北排序。

## 立直成本推演

1. 将当前视角点数设置在前后名之间，确认支付 1000 点后即时顺位和四家点数正确。
2. 构造支付 1000 点后掉位的场景，确认页面显示警告状态。
3. 将当前视角点数设置为 900，确认页面提示无法支付立直棒且不扣点。
4. 确认该区块只描述宣言后即时顺位，不给出和率或是否应该立直的结论。

## 荒牌流局推演

1. 仅选择当前视角听牌，确认三名未听玩家各支付 1000 点。
2. 选择两家听牌，确认两名未听玩家各支付 1500 点。
3. 分别选择全员听牌和全员未听，确认不产生罚符支付。
4. 选择庄家听牌，确认显示连庄和下一本场；取消庄家听牌，确认显示通常轮庄。
5. 确认供托数量在流局后保持不变，切换听牌状态不会修改真实牌局。

## 本地三麻

1. 首页选择“单机算点”，再选择“三人麻将”。
2. 确认工作台展示“局势分析 / 点数推演”入口，默认以当前庄家为分析视角。
3. 点击进入详情页，确认只展示东、南、西三个视角，以及升一、升二和跌三风险，不出现北家或第四位。
4. 将北家点数设置为明显高于三家，确认北家仍不参与顺位、目标、风险和结算结果。
5. 依次切换东、南、西视角，确认荣和对象只有另外两家，自摸结果只包含两名对手支付。
6. 选择南三局，确认标记为默认半庄终局；将三家设为同点，确认顺位按东、南、西排列。
7. 在荒牌流局推演中只选择一家听牌，确认另外两家各支付 1500 点；全员听牌或未听时不产生支付。
8. 构造支付立直棒后掉位的场景，确认只在三家之间重排顺位。
9. 返回算点桌面完成一局三麻结算，确认原有算点和结算功能不受影响。

## 未满员在线房间

1. 使用免费用户创建在线房间，仅房主一人进入。
2. 确认工作台已经展示局势分析入口，不再提示等待四位玩家加入。
3. 点击进入详情页，确认默认分析视角为房主绑定的座位。
4. 确认页面自动显示“已同步”、同步时间和当前房间版本。
5. 切换到空座位，确认页面使用本地玩家名兜底并能正常计算，不改变牌桌上的“等待加入”状态。
6. 点击刷新，确认只更新分析数据，不修改房间版本、点数或局况。

## 完整在线房间

1. 至少两名用户加入同一房间并选择不同座位。
2. 分别打开局势分析，确认每名用户默认使用自己的座位视角。
3. 房主修改点数、本场或供托后，成员刷新房间再进入分析。
4. 确认双方看到的基础点数一致，但默认视角分别对应本人座位。
5. 保持成员停留在分析页，房主再次修改点数；成员点击刷新后确认版本、点数和分析结果更新。
6. 临时断开网络后点击刷新，确认页面保留原分析并明确提示当前为缓存数据及缓存时间。

## 点数边界抽查

- 荣和抽查：1000、1300、2600、3900、5200、7700、满贯及役满。
- 自摸抽查：庄家与子家支付结构、本场每家 100 点、供托全部计入和牌者。
- 同点抽查：两家或四家同点时，顺位稳定且切换视角不会改变排序规则。
- 负点抽查：推演后玩家低于 0 点时保留负号，例如 `-1,000`，不得显示为 `0`。
- 高点抽查：倍满、三倍满和多倍役满场景不溢出，无法达到目标时给出明确空状态。
