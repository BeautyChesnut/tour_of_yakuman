# UI 原型图生成说明

本说明用于记录本次 gpt-image 原型图生成意图，后续可继续迭代。

## 目标

生成微信小程序立直麻将算点工具的移动端 UI 原型图，用于评估下一阶段 UI 优化方向。

## 原型画面

需要展示 4 个手机界面：

1. 主工作台：上方场况区、中间虚拟牌桌、下方结算区。
2. 本局事件弹层：选择放铳、自摸、流局；流局可选择四家听牌状态。
3. 牌选择弹层：四行牌盘，万/索/筒/字，数字 1-9 和 0 赤五；用于手牌、和牌张、宝牌、鸣牌复用。
4. 确认结算弹窗：展示局况、事件、手牌数量、宝牌数量、预计结算摘要。

## 关键约束

- 风格为低保真到中保真产品原型，不要做营销海报。
- 中文界面。
- 手机竖屏微信小程序。
- 主界面分为三段：
  - 顶部：场况区，显示东一局、0 本场、0 供托，以及记录、回退、重置按钮。
  - 中部：虚拟牌桌，展示东南西北四家、点数、点差、立直状态。
  - 底部：结算区，展示本局事件、场面番型、宝牌、手牌、鸣牌和确定结算按钮。
- 手牌区域必须显示 13 张手牌 + 1 张和牌张，同一行但和牌张要有明确分隔和标识。
- 鸣牌区域按 4 格一组展示，体现吃、碰、明杠、暗杠、加杠类型。
- 牌选择面板后续会替换为麻将牌 icon，本次可以用文字和简化牌面符号表达。
